# Troubleshooting (symptom → cause → fix)

Run `npm run doctor` first: it checks tools, `app/.env`, network reachability
and the Trustless Work key.

| Symptom                                                                                                          | Cause                                                                                              | Fix                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Logs say "Starting local Stellar Docker container… Local Stellar network is healthy"                             | cosmetic message from Scaffold CLI 0.0.27; `development` targets testnet here                      | ignore it: no Docker is needed or used (the next lines say "Using network at https://soroban-testnet.stellar.org")                                                                                                                |
| Vite: "Port 5173 is already in use"                                                                              | another dev server holds the port; the port is fixed because Cavos only accepts registered origins | stop the other server (or the old `npm start` of this project) and run `npm start` again                                                                                                                                          |
| `npm install` reports vulnerabilities / "allow-scripts" warnings                                                 | dependency audit noise                                                                             | ignore; never `npm audit fix --force` (it breaks the pinned SDKs)                                                                                                                                                                 |
| `stellar: command not found`                                                                                     | Stellar CLI missing                                                                                | macOS: `brew install stellar-cli`. Others: `cargo install --locked stellar-cli` or binaries from https://github.com/stellar/stellar-cli/releases                                                                                  |
| `error: no such command: scaffold` / `stellar scaffold` unknown                                                  | plugin missing                                                                                     | `cargo binstall stellar-scaffold-cli` or `cargo install --locked stellar-scaffold-cli` (or download `stellar-scaffold` from https://github.com/stellar-scaffold/cli/releases and put it on PATH)                                  |
| `can't find crate for core` / `wasm32v1-none` target missing                                                     | Rust target not installed                                                                          | `rustup target add wasm32v1-none` (rustup reads `rust-toolchain.toml` automatically)                                                                                                                                              |
| `linker 'lld' not found`                                                                                         | Rust without rustup (Nix/distro)                                                                   | Use rustup, or install LLVM's lld (`brew install lld`)                                                                                                                                                                            |
| `scaffold.yml uses schema version 2, but this CLI supports version 1`                                            | ran `stellar scaffold init` (template moved to v2)                                                 | Don't init: clone/fork this repo. To init elsewhere: `STELLAR_SCAFFOLD_UI_REPO="stellar-scaffold/ui#main_contracts_guess_the_number_guess-the-number_pkg0.0.2_cli27.0.0" stellar scaffold init my-app --template react -p npm -y` |
| `tsc`: TS2307 `Cannot find module '@stellar-scaffold/app-lib/clients'` / "Contract clients aren't generated yet" | fresh clone, nothing built yet                                                                     | `npm run contracts:build` once (or `npm start`), then retry                                                                                                                                                                       |
| Vite: `Failed to resolve import "@stellar-scaffold/app-lib/clients"`                                             | clients not generated yet                                                                          | Wait for the first `stellar scaffold watch` build to finish; or run `npm run contracts:build`. Check the "stellar" logs for the real error                                                                                        |
| App talks to `localhost:8000`                                                                                    | `app/.env` missing or invalid `PUBLIC_STELLAR_NETWORK`                                             | `cp app/.env.example app/.env` (doctor does it), values must be `TESTNET` + testnet URLs. Restart `npm start`                                                                                                                     |
| `Failed to generate client for: X` + `HostError` in logs                                                         | constructor/after_deploy failed on chain                                                           | Read the diagnostic event list (newest first). Check `constructor_args` names match the Rust params (`--admin me`)                                                                                                                |
| `❌ Failed to generate client for: X: npm run build failed with status: Some(2)` (empty error)                   | the TS client doesn't compile, most often an argument named `options`                              | rename the argument (e.g. `choices`); reproduce with `stellar contract bindings typescript --wasm target/wasm32v1-none/release/<crate>.wasm --output-dir /tmp/x` + `npm run build` there                                          |
| `useSubscription` never fires                                                                                    | old filter matched only single-topic events                                                        | fixed in `app-lib/subscription.ts` (`"**"` wildcard); pass the event's snake_case name as `topic`                                                                                                                                 |
| Contract key not found / wrong client name                                                                       | env key ≠ crate name with `_`                                                                      | `my-crate` → `my_crate` in environments.toml → `myCrate` in TS                                                                                                                                                                    |
| Wallet says "network mismatch" / tx fails to sign                                                                | wallet on Mainnet/Futurenet                                                                        | Switch Freighter to **Testnet**                                                                                                                                                                                                   |
| `op_no_trust` / `trustline missing`                                                                              | account has no USDC trustline                                                                      | "Add trustline" in Escrow Studio setup                                                                                                                                                                                            |
| `op_underfunded` / `tx_insufficient_balance`                                                                     | not enough XLM/USDC                                                                                | Friendbot (XLM), swap XLM→USDC (Escrow Studio)                                                                                                                                                                                    |
| `Error(Auth, InvalidAction)`                                                                                     | wrong signer for `require_auth`                                                                    | sign with the address the contract expects                                                                                                                                                                                        |
| `Error(Contract, #N)`                                                                                            | your `#[contracterror]` variant N                                                                  | map N to the enum in the contract source                                                                                                                                                                                          |
| `Error(Storage, MissingValue)`                                                                                   | reading a key that was never set or expired                                                        | use `.get(..).unwrap_or(..)`, check TTL extension                                                                                                                                                                                 |
| Testnet contracts disappeared                                                                                    | testnet is reset periodically                                                                      | delete `app/.config/stellar/contract-ids/*.json` and restart `npm start` (redeploys)                                                                                                                                              |
| Friendbot 400                                                                                                    | account already funded                                                                             | ignore                                                                                                                                                                                                                            |
| Trustless Work 401                                                                                               | missing/invalid `PUBLIC_TRUSTLESS_WORK_API_KEY`                                                    | get a key at https://dapp.trustlesswork.com, put it in `app/.env`, restart                                                                                                                                                        |
| Trustless Work 429                                                                                               | ~50 req/min per key                                                                                | stop polling, wait a minute                                                                                                                                                                                                       |

Windows: use WSL2 or Git Bash. If `.claude/skills/*` show up as small text
files, run `npm run agents:sync` (git checked symlinks out as files).
